# Chapter 3 大学中庭资源

用途：作为大学新生周 / 履历经营阶段的干净场景资产，供游玩文档和后续场景搭建参考。

## 文件

- `backgrounds/university_courtyard_interactables.png`：不带 HUD、摇杆、按钮、玩家角色和 NPC 的大学中庭背景图，仅保留项目公告板、星环 AI 路径建议终端、社团招新桌等可交互元素与热点提示。

## 设计约束

- 与 `assets/storyline` 下其他背景资源保持一致，优先服务游戏场景搭建，而不是完整 UI 截图展示。
- 可交互元素应表达 Chapter 3 的核心压力：自由的大学空间、社团机会、项目竞争和 AI 路径建议同时存在。
